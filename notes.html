第一部分基础：术语、评估与度量

西瓜书前两章。这一部分的概念辨析是科目四机器学习板块最直接的命题点——不考推导，考「分得清」。

ML1绪论：术语一网打尽 高频★★★

① 什么是「学习」：Mitchell 形式化定义

设 P = 程序在任务类 T 上的性能，E = 经验（历史数据集）。若程序利用经验 E 在任务 T 上使性能 P 得到改善，则称该程序对 E 进行了学习。
术语含义易混点
数据集 / 样本所有记录的集合 / 每一条记录（instance、example）统计学家叫「观测/变量」，数据库叫「记录/字段」，机器学习叫「样本/属性」——同一件事三种叫法
特征向量 / 维数一个样本在坐标轴上的点 / 特征个数维数极大即「维数灾难」，是第 11 章降维的出发点
训练集 / 测试集用于学习的样本集 / 用于检验的样本集二者必须互斥，否则评估过于乐观
泛化能力模型适用于新样本的能力，即从特殊到一般学习的目标不是训练误差小，而是泛化误差小
分类 / 回归预测离散值 / 预测连续值—
监督 / 无监督训练数据有标记 / 无标记聚类、关联规则属无监督；分类、回归属监督

② 五大学习范式全景 拓展

按「有没有标记 × 怎么给反馈」可以把机器学习切成五块：监督（有标记，学 x→y 的映射）、无监督（无标记，学数据自身结构）、半监督（少量标记 + 大量未标记）、自监督（用数据自身构造伪标记，如语言模型的「遮词预测」）、强化学习（不给答案只给奖赏，在试错中学策略）。
范式数据形态典型算法精算里的对应场景
监督学习(x, y) 成对线性回归、Logistic、决策树、SVM、神经网络索赔发生概率预测、续保预测、欺诈标签已知时的识别
无监督学习只有 xK-Means、DBSCAN、PCA、Apriori客户分群、风险画像、特征压缩
半监督学习少量 (x,y) + 大量 x协同训练、TSVM、伪标签欺诈案件只有极少数被核实，其余未核实
自监督学习自己造标签对比学习 SimCLR、BERT 的 MLM无标签的庞大理赔文本、医疗影像预训练
强化学习状态-动作-奖赏序列Q-learning、PPO、DQN动态定价、续保营销策略、资产配置（学界探索）

③ 假设空间、归纳偏好与「没有免费的午餐」 拓展

假设空间：算法所有可能输出的映射（函数）的集合；与训练集一致的假设集合叫版本空间。
归纳偏好：当多个假设都能解释训练数据时，算法必须有所偏好才能选出唯一模型——「喜欢什么样的模型」就是它的归纳偏好。最常见的偏好是奥卡姆剃刀：若有多个假设与观察一致，选最简单的那个。
NFL 定理（No Free Lunch，没有免费的午餐）：在所有可能的问题上按均匀分布平均，任意两个算法的期望性能完全相同。结论不是「算法无优劣」，而是——脱离具体问题谈「哪个算法更好」毫无意义。必须结合问题本身的分布假设（这就是归纳偏好的价值）。
口诀：算法好不好，问问题不问算法。NFL 定理是「具体问题具体分析」的数学版——这也是为什么保险定价上 GBM 常常赢 GLM，但在小样本、强监管的场景 GLM 依然不可替代。

④ 统计学习三要素：模型 · 策略 · 算法

模型：要学的函数形式（如线性模型 y = wTx + b、决策树、神经网络）。
策略：什么叫「学得好」——定义损失函数（一次预测的好坏）与风险函数（平均意义下的好坏），按经验风险最小化（ERM）或结构风险最小化（SRM，即 ERM + 正则项）来选择模型。
算法：如何高效地求出最优参数（最小二乘闭式解、梯度下降、SMO、BP）。
与本站 CH.06 的关系：CH.06 讲的就是这三要素在考纲层面的表述，本页是它的放大版——同一套骨架，本页填进十七章的血肉。
考点视角：常以选择题形式给出一句话描述，让你判断属于哪个术语（尤其「泛化能力」「监督/无监督」「维数灾难」）。记住判定链条：有没有标记 → 监督还是无监督；预测值离散还是连续 → 分类还是回归。若考「NFL 定理」，正确理解是「不能脱离具体问题评价算法」。

ML2模型的评估方法：三种划分 高频★★★

① 留出法（hold-out）

D = S ∪ T，S ∩ T = ∅；常见 2/3 ~ 4/5 用于训练。要分层抽样保持类别分布一致；单次划分不稳定，应多次随机划分取平均。

② k 折交叉验证（k-fold CV）

D 分为 k 个大小相同的互斥子集，每次取 k−1 个训练、余下 1 个测试，返回 k 次均值。常用 k=10；k=m（每折 1 个样本）即留一法——评估准确但计算量巨大。

③ 自助法（bootstrap）

m 次有放回采样得 D′，样本始终不被采到的概率 → e−1 ≈ 36.8%，故 D′ 训练、(D−D′) 测试（袋外估计）。适合小数据集；缺点是改变了初始分布、引入估计偏差。
口诀：留出「一次分两半」、交叉「轮流当测试」、自助「有放回，三成六」。数据集够大用前两种，数据小才用自助。
⚠ 易错：那个 36.8% 是 极限值（(1−1/m)m → e−1），不是精确等于；选择题里出现「约 36.8%」才是对的。另外调参完成后，要用完整数据集 D 重新训练一次——这点常被忽略。

④ 三个集合的分工与调参陷阱 拓展

训练集（拟合参数）→ 验证集（选超参、早停）→ 测试集（只在最后用一次，估计泛化性能）。三者的信息不能互相「漏」：用测试集反复调参，等于把测试集变成了验证集，报告出来的泛化性能必然过于乐观。
嵌套交叉验证：外层估计性能、内层调超参，两层独立，避免「调参污染评估」。
分层 k 折：分类问题中每折保持类别比例一致。
分组 / 时间序列切分：同一被保险人的多条记录必须放在同一折（否则个体信息泄漏）；带时间的数据必须按时间切——用未来数据预测过去，是保险建模最常见也最致命的泄漏。
精算提醒：OOT（Out-of-Time）验证 保险数据天然带时间属性。实务上的标准做法是：训练集 = 早期年度，验证集 = 最近一年，测试集 = 最近半年（OOT）。 随机 k 折会把同一保单的后续年度放进训练、把前期放进测试，让模型「偷看未来」，线下 AUC 很高、上线立刻崩。这个坑比算法选择重要十倍。
考点视角：命题形式多为「下列关于评估方法的说法，正确的是」——重点测：① 留出法需分层抽样；② k 折常用 10 折；③ 留一法准确但开销大；④ 自助法改变了数据分布。四个说法能分辨即可。

ML3性能度量：从准确率到 AUC 高频★★★

① 回归任务的度量

MSE = (1/m)Σ(f(xi) − yi)2；RMSE = √MSE（与 y 同量纲）；MAE = (1/m)Σ|f(xi) − yi|（对异常值更稳健）；R² = 1 − SSE/SST（解释掉的方差比例）。
保险里的索赔金额分布右偏、零膨胀，实务更常用 RMSE 的对数版 / Tweedie deviance / 基尼系数，纯 MSE 会被个别巨额赔案牵着走。

② 分类：错误率、查准率、查全率、F1

错误率 E = 分错样本数 / 总数；精度 Acc = 1 − E。
查准率 P = TP/(TP+FP)（推出来的里面有多少是对的）；查全率 R = TP/(TP+FN)（该推出来的推出来了多少）。
F1 = 2PR/(P+R)（调和平均）；更一般地 Fβ = (1+β2)PR/(β2P + R)，β>1 偏重查全、β<1 偏重查准。
⚠ FN 与 FP 别搞反：FN 是「真的为正、被判成负」（漏报），FP 是「真的为负、被判成正」（误报）。按字面 False→Negative 去理解会正好反掉。保险语境记忆：欺诈识别里 FN 是「真欺诈没抓到」（赔钱），FP 是「好客户被误判」（伤体验）——前者代价通常更高，所以要看代价敏感。

③ ROC、AUC 与 P-R 曲线

ROC：横轴 FPR = FP/(FP+TN)，纵轴 TPR = R = TP/(TP+FN)。AUC = ROC 曲线下面积，衡量排序质量：AUC=1 表示所有正例排在负例之前，0.5 表示随机。
P-R 曲线：查全率为横轴、查准率为纵轴；曲线被完全包住则对方更优，交叉时看平衡点 BEP（P=R 处取值）。
图一 · P-R 曲线与 ROC 曲线对照：P-R 关注「查得准/查得全」，ROC 关注「排序质量」；类别极不平衡时 P-R 更能暴露问题。

④ 代价敏感与阈值选择 拓展

代价敏感错误率：cost01（正判成负）与 cost10（负判成正）不相等时，最小化总体代价而非错误率；对应「代价曲线」，横轴为正例概率代价、纵轴为归一化代价，ROC 上每点对应一条线段，取下界围成的面积即期望总体代价。
二分类里「阈值怎么定」其实是一道期望代价最小化题：设正例占比 π、漏报代价 CFN、误报代价 CFP，则把样本判为正的期望代价是 (1−p̂)·π·CFN，判为负的期望代价是 p̂·(1−π)·CFP；两者相等处即最优阈值
p* = π·CFN / [π·CFN + (1−π)·CFP]。

⑤ 信用评分与精算常用的四件套 拓展

指标定义 / 直观解释取值与好坏在保险里的用法
KSKS = max|TPR − FPR|，即 ROC 曲线到对角线的最大垂直距离，代表模型最强的区分能力出现在哪个切点0~1，越大越好；业界 >0.3 算可用，>0.5 罕见核保评分卡、欺诈模型的首选汇报指标
Gini基尼系数与 AUC 是同一件事的两种刻度：Gini = 2·AUC − 10~1；AUC=0.5 → Gini=0（无区分）车险定价模型的标准汇报口径（欧洲常用）
Lift / GainLift = 某分位内的正例密度 / 总体正例密度；Gain（捕获率）= 前 q% 样本里抓住了多少正例Lift 越大越集中；Gain 图越靠左上越好「查前 5% 的高风险件能覆盖多少欺诈」
Log Loss / BrierLog Loss = −(1/m)Σ[y ln p̂ + (1−y) ln(1−p̂)]；Brier = (1/m)Σ(ŷ−y)²，度量概率校准而非排序越小越好；与 AUC 不完全同向若预测概率要进定价公式，必须看校准（AUC 高 ≠ 概率准）
为什么精算师不能只看 AUC？ AUC 只评价排序，不评价水平。把全部预测概率乘以 0.5，AUC 一点不变，但期望索赔成本的估计会全错——定价、准备金、资本模型要的是**校准后的概率**。 所以实务上要看：AUC/KS（区分度）+ 校准曲线（可靠性）+ 实际 vs 预期的分位对比图。必要时做 Platt 缩放或等距回归（isotonic regression）校正。
考点视角：三件事必考——① P/R/F1 的定义与相互制约（P 高则 R 低）；② AUC 的含义（排序质量、0.5 为随机）；③ 类别不平衡时准确率失效（正例 99% 时全猜正也有 99% 准确率）。保险应用：理赔欺诈识别正例极少，必须看 P-R 而不是准确率。

ML4比较检验与偏差-方差 中频★★

① 四个比较检验

假设检验：用测试错误率推测泛化错误率的分布（二项检验 / t 检验）。
交叉验证 t 检验：两学习器在相同折上成对比较差值。
McNemar 检验：二分类专用，若性能相同则 e01 = e10，统计量 (|e01−e10|−1)2/(e01+e10) ~ χ2(1)。
Friedman 检验：多数据集多算法排序（赋序值 1,2,…），超出临界值则拒绝「性能相同」，再用 Nemenyi 后续检验两两比较（看平均序值差是否超过临界值域 CD）。

② 偏差-方差分解（含推导）

期望泛化误差 = 偏差2 + 方差 + 噪声。
偏差 = 预测期望与真实值的偏离，刻画拟合能力；方差 = 每次预测相对预测期望的离散，刻画稳定性。
回归 + 平方损失下可严格证明：设真实 y = f(x) + ε，E[ε]=0、Var(ε)=σ²，模型 f̂ 在训练集 D 上的预测，则
ED[(y − f̂(x))2] = bias2(f̄ − f)2 + var ED[(f̂ − f̄)2] + σ²（不可约误差）。
三项之和即泛化误差——噪声项无法通过任何算法消除。

③ 欠拟合与过拟合：判断与处置

口诀：欠拟合——训练误差和测试误差都大，偏差主导；过拟合——训练误差极小而测试误差变大，方差主导。过拟合是机器学习的关键障碍，没有彻底的解决方案，只能缓解（正则化、剪枝、早停、增数据）。
处置手段作用机制适用模型
正则化 L1/L2限制参数规模，压低方差线性模型、神经网络（weight decay）
早停 early stopping在验证误差拐点处停止训练神经网络、GBDT（n_estimators）
剪枝 / 深度限制直接降低模型复杂度决策树、树集成
dropout / 噪声注入随机丢弃单元，迫使网络不依赖单点特征神经网络
数据增强 / 增数据唯一从根源上降低方差的办法通用（保险业往往做不到，只能靠特征与约束）
集成（Bagging）平均掉个体模型的波动不稳定学习器（树、网络）
考点视角：简答题常问「什么是过拟合，如何缓解」，按四招作答：正则化 / 早停 / 剪枝 / 增加数据或数据增强，再补一句「过拟合无法彻底避免」。

第二部分监督学习：六大模型

从最简单的线性回归，到曾经取代过神经网络的 SVM。这一部分是「原理 + 方法」的主战场。

ML5线性模型：回归 · 对数几率 · LDA 高频★★★

① 线性回归与最小二乘

一元：最小化均方误差，对 w、b 求偏导置零 → 最小二乘解。
多元：ŷ = wTx + b，矩阵形式 ŵ* = (XTX)−1XTy（仅当 XTX 满秩可逆；否则需正则化）。
几何意义：把 y 正交投影到 X 的列空间上，残差垂直于列空间。
广义线性模型 GLM：y = g−1(wTx + b)，g(·) 为联系函数；取 g = ln 即得对数线性回归。（精算定价里的 Poisson 回归、Gamma 回归正是 GLM 家族成员，见本站 CH.04 与第七部分 ML22。）

② 对数几率回归（Logistic）

y = 1/(1 + e−(wTx+b))，把线性回归的预测值压到 (0,1)；等价于用线性模型逼近真实标记的对数几率 ln[y/(1−y)]。参数由极大似然估计（不是最小二乘）。
损失视角 拓展：极大似然 ≡ 最小化对数损失（交叉熵） L = −Σ[yi ln p̂i + (1−yi) ln(1−p̂i)]。它是凸函数，故 Logistic 有全局最优解；梯度形式优雅——∂L/∂w = XT(p̂ − y)，即「预测与实际的差」乘以特征，与线性回归的梯度长得一模一样（差别只在 p̂ 经过了 Sigmoid）。
⚠ 别混淆：Logistic 名字里有「回归」却是分类方法；它用极大似然而非最小二乘；输出是概率而非类别（要类别需再定阈值）。

③ 多分类与 Softmax 回归 拓展

拆分策略：OvO（N(N−1)/2 个二分类器，投票）、OvR（N 个，一对其余）、MvM（若干正类 vs 若干反类，常用 ECOC 编码，按海明/欧氏距离解码）。
Softmax 回归（多项 Logistic）：直接对 K 类建模 P(y=k|x) = ewkTx / Σj ewjTx，K 个输出天然归一化，是神经网络分类头的标准配置。

④ LDA 线性判别分析

把样本投影到一条直线，使同类投影尽可能近、异类投影尽可能远；最大化「广义瑞利商」= 类间散度 / 类内散度。LDA 用到类别标记，因此也是一种监督降维技术（可降到 N−1 维，N 为类别数）。

⑤ 类别不平衡三招

欠采样（EasyEnsemble，丢掉多数类）、过采样（SMOTE 在 minority 样本间插值造新样本）、再缩放（阈值移动，也是代价敏感学习的基础）。
三者的共同点：都在改数据或改阈值，而不是改模型；评估时务必回到原始分布的测试集上报告结果，否则指标虚高。
考点视角：① Logistic 与线性回归的区别（前者分类 + 极大似然，后者回归 + 最小二乘；前者输出经 Sigmoid 压缩到 (0,1)）；② LDA 与 PCA 的区别（LDA 用标记、监督降维、最多 N−1 维；PCA 不用标记、无监督、维数自选）。这两组对比是高频辨析题。

ML6决策树：ID3 / C4.5 / CART 高频★★★

① 三个划分准则

信息熵：Ent(D) = −Σk pk log2 pk（值越小越纯，二分类时最大为 1）。
信息增益（ID3）：Gain(D, a) = Ent(D) − Σv |Dv|/|D| · Ent(Dv)，取最大者划分。
增益率（C4.5）：Gain_ratio = Gain(D,a) / IV(a)，其中 IV(a) = −Σv |Dv|/|D| · log2(|Dv|/|D|)（属性 a 的固有值，取值越多越大）。C4.5 先筛出高于平均的候选，再从中选增益率最大的。
基尼指数（CART）：Gini(D) = 1 − Σk pk2，反映「随机抽两个样本类别不一致的概率」，越小越纯。
⚠ ID3 的坑：信息增益偏向取值数目多的属性——极端情况「编号」属性会把每个样本单独分一支，熵为 0 却毫无用处。这正是 C4.5 引入增益率的原因。

② 连续值与缺失值

连续值：二分法——排序后取相邻均值作为候选切点（n−1 个），选信息增益最大的切点。
缺失值：① 仅在无缺失的子集上算信息增益，再乘以该子集占比；② 缺失样本按各分支样本比例作为权重同时划入所有分支。

③ 剪枝：预剪枝 vs 后剪枝

预剪枝：生成时评估，不提升就不分支——省时间但有欠拟合风险（有些分支当前不涨、后续会涨）。
后剪枝：生成完整树后自底向上考察——开销大但泛化通常更好。代价复杂度剪枝 CCP（CART 用）：最小化 Rα(T) = R(T) + α|T|，α 越大树越小，用验证集选 α。

④ 回归树与树的四个天然优势 拓展

回归树：叶子输出该区域样本 y 的均值，划分准则改为最小二乘误差下降（CART 回归用平方误差，GBDT 的基学习器就是它）。
树的优势：① 不需要标准化（只比大小）；② 天然处理非线性与特征交互（一条路径 = 一个交互项）；③ 对缺失值与异常值鲁棒；④ 结果可解释（一条路径就是一条 IF-THEN 规则）。
树的劣势：方差大（对样本扰动敏感）、外推能力差（回归树无法预测超出训练范围的 y）、阶跃式边界不够平滑。
口诀：ID3 看增益、C4.5 看增益率、CART 看基尼；连续值用二分、缺失值用权重；预剪枝贪心、后剪枝更准。
考点视角：必考三选一式的对应（算法 ↔ 划分准则），以及剪枝的两种策略对比。可能会给一个小数据集让你算熵或信息增益——本站 CH.06 有「熵与基尼指数」演算器可练手。

ML7神经网络：从 M-P 到 BP 中频★★

① M-P 神经元与激活函数

接收 n 个带权输入 → 求加权和 → 减去阈值 → 经激活函数输出。理想激活是阶跃函数，但不连续不光滑，实际常用 Sigmoid（把输入挤到 (0,1)，又称挤压函数）。
激活函数全家福 拓展：
Sigmoid：(0,1)，两端饱和 → 梯度趋 0（梯度消失）；
Tanh：(−1,1)，零中心，同样会饱和；
ReLU：max(0,x)，计算极快、正区间不饱和，现代网络默认；缺点是「死亡 ReLU」（一旦进入负区间梯度恒为 0，神经元永久失效）；
LeakyReLU / ELU / GELU / Swish：对负区间给一点斜率或平滑过渡，缓解死亡问题；
输出层：二分类用 Sigmoid、多分类用 Softmax、回归用恒等。

② 感知机：只能解线性可分

两层神经元，仅输出层是功能神经元；权重更新 Δwi = η(y − ŷ)xi（η∈(0,1) 为学习率）。只有一层功能神经元 ⇒ 只能处理线性可分（异或 XOR 解不了）。多层功能神经元即可解任意形状的划分。

③ 多层前馈网络与 BP 算法

结构：每层与下一层全互连、无同层连接、无跨层连接；「前馈」指拓扑上无环，不等于不能反向传播。
BP：误差逆传播 + 梯度下降，以单个样本的均方误差之负梯度调节连接权与阈值；标准 BP 每次针对单个样本更新（随机性有助跳出局部极小、收敛更快），累积 BP 读完全部数据才更新一轮（数据量大时标准 BP 往往更好）。
本质：BP 就是链式法则 + 动态规划——从输出层往回逐层算梯度，复用已算出的中间结果。

④ 缓解过拟合与局部极小

早停（训练集误差降而验证集误差升时停止）+ 正则化（误差函数中加入权值平方和项，λ 折中拟合与复杂度）。
局部最小 vs 全局最小：梯度为 0 即局部极小；跳出手段——多组不同初值初始化取最优、模拟退火、随机梯度下降（噪声本身能帮忙跳出鞍点）。

⑤ 深度学习与「表示学习」

增加隐层数比增加每层神经元更有效；多隐层难训的两条路——无监督逐层预训练 + 微调（如 DBN）、权共享（如 CNN）。本质上是表示学习/特征学习，把人工特征工程自动化。深度学习的三大支柱：更大的数据 + 更深的结构 + 更强的算力。
考点视角：① 感知机只能解线性可分、XOR 需多层；② 激活函数为何不用阶跃（不连续、不可导）；③ 早停与正则化的作用；④ 深度学习 = 自动特征工程。以概念题为主，不考反向传播的矩阵推导。

ML8支持向量机：间隔、对偶与核 中频★★

① 两种间隔

函数间隔 = ŷ(wTx + b) = |wTx + b|（会随 w、b 同比例缩放而变，故不能用来最大化）；几何间隔 = ŷ(wTx + b)/‖w‖，即点到超平面的真实距离。

② 基本型与支持向量

令几何间隔为 1，则最大化间隔 ⇔ 最小化 ½‖w‖2，约束 yi(wTxi + b) ≥ 1 —— 一个凸二次规划问题。
满足 y(wTx+b) = 1 的样本即支持向量；非支持向量对应的拉格朗日乘子 αi = 0，因此预测时只需与支持向量求内积。这也是 SVM 稀疏性的来源。

③ 为何转对偶

① 更易求解；② 自然出现内积形式，从而引出核函数。对偶问题：max Σαi − ½ΣΣαiαjyiyjxiTxj，s.t. Σαiyi = 0，αi ≥ 0；由 SMO（固定其他变量、每次只优化两个 α，有解析解）求解。

④ 核函数：低维计算，高维表现

κ(xi, xj) = ⟨φ(xi), φ(xj)⟩，直接算出高维空间中的内积而不必显式写出映射。常用：线性核、多项式核、高斯（RBF）核 κ = exp(−‖x−x′‖²/2σ²)、Sigmoid 核。
Mercer 条件 拓展：一个函数能当核函数，当且仅当它对任意有限样本集构成的核矩阵半正定。RBF 核对应无穷维特征空间，γ 越大越容易过拟合（每个样本附近都鼓一个包）。核函数选择是 SVM 最大的变数。

⑤ 软间隔与 C 的含义

允许少量样本不满足约束，引入松弛变量 ξi 与 hinge 损失 max(0, 1 − y·f(x))；目标 ½‖w‖2 + C·Σξi。对偶形式与硬间隔完全相同，只是 α 多了上限 C。C 越大越不容忍犯错（趋向硬间隔、易过拟合），C 越小越宽容。
SVM 与 Logistic 的隐秘联系 拓展 两者都是「线性模型 + 凸损失 + 正则项」：SVM 用 hinge 损失，Logistic 用对数损失，正则项都是 ½‖w‖²（对应 C 的倒数）。 区别在于 hinge 损失对「分对且很有把握」的样本不产生任何损失 ⇒ 解只由支持向量决定；对数损失对所有样本都有梯度 ⇒ 所有样本都参与，因此 Logistic 对噪声更敏感，但能输出概率。要概率选 Logistic，要鲁棒边界选 SVM。
口诀：函数间隔会缩放、几何间隔才是真距离；支持向量定边界、非支持向量 α 全为零；核函数低维算高维；C 大不容错、C 小更宽容。
考点视角：常考三点——① 支持向量的定义与「只与支持向量有关」；② 核函数的作用（避免显式高维映射、解决线性不可分）；③ 软间隔与 C 的含义。公式推导一般不要求。

ML9贝叶斯分类器与 EM 算法 中频★★

① 贝叶斯判定准则与两类建模路线

最小化条件风险 R(c|x) = Σ λij P(cj|x)；取 0-1 损失时退化为「选后验概率最大的类」。
生成式 vs 判别式：生成式先对联合分布 P(x,c) 建模再求 P(c|x)（贝叶斯、高斯混合、HMM）；判别式直接对 P(c|x) 或决策边界建模（Logistic、决策树、神经网络、SVM、CRF）。
一般规律：生成式收敛更快（需要更少数据），判别式渐近误差更小。

② 朴素贝叶斯

假设属性条件独立，P(c|x) ∝ P(c)·Πi P(xi|c)。MLE 四步：写似然 → 取对数 → 求偏导置零 → 解似然方程组。
拉普拉斯修正：P̂(c) = (|Dc|+1)/(|D|+N)，P̂(xi|c) = (|Dc,xi|+1)/(|Dc|+Ni)，避免某个属性值未出现导致概率被抹成 0。

③ EM 算法：隐变量时代的利器

存在隐变量时的参数估计利器。E 步——固定 θ，求隐变量 Z 的期望（实为后验概率，建立对数似然的下界）；M 步——固定 Q，最大化下界更新 θ。用 Jensen 不等式把「和的对数」变成「对数的和」。
可视为一种坐标下降：一次固定一个变量、对另一个求极值，交替直到收敛（每步都让似然单调不减，但只能保证收敛到局部极值）。

④ 从 EM 到变分推断 拓展

EM 的每一步都在最大化证据下界 ELBO：ln P(x|θ) ≥ Eq[ln P(x,Z|θ)] − Eq[ln q(Z)]，当 q(Z) = P(Z|x,θ)（真实后验）时等号成立。
当后验算不出来（模型太复杂）时，就退而求其次——限定 q 的形式族、只优化 ELBO，这就是变分推断 VI；VAE 的编码器正是「用神经网络参数化的 q(Z)」。另一条路是MCMC 采样（本站 CH.03）：不用解析形式，靠抽样逼近后验。VI 快而有偏、MCMC 准而慢。
与本站 CH.03 随机模拟的联系：EM 的思路与 Gibbs 采样、MCMC 同属「隐变量/高维积分难求时的迭代策略」，只是 EM 求的是点估计（极大似然），MCMC 求的是分布。K-Means 其实也是 EM：类别=隐变量、类中心=参数。
考点视角：① 先验概率 vs 后验概率；② 为何要拉普拉斯修正；③ EM 两步各做什么（E 步求期望/下界，M 步极大化）。「K-Means 是 EM 的特例」是很好的简答加分句。

第三部分集成学习与无监督学习

「三个臭皮匠」的数学（集成），以及没有标准答案时怎么找结构（聚类、降维）。

ML10集成学习：好而不同 高频★★★

① 核心矛盾：准确性与多样性不可兼得

集成要有效，个体学习器必须「好而不同」。若基分类器独立且错误率均为 ε，集成错误率 = Σk>T/2 C(T,k) εk(1−ε)T−k，随 T 指数下降；但现实中独立性不可能成立（这是 Hoeffding 不等式失效的地方），故只能尽量制造差异。
数学表达：集成的泛化误差 = 平均个体误差 − 平均多样性项。误差↓与差异↑是一对矛盾，这就是「好而不同」。

② Boosting / AdaBoost：串行，降偏差

串行生成，不断加大上一轮分错样本的权重，最后按误差率加权组合（误差率小的权重大）。使用指数损失函数；标准版只适用于二分类。主要降低偏差——每一轮都在补前一轮的缺口，把弱学习器抬成强学习器。

③ Bagging 与随机森林：并行，降方差

Bagging：并行生成，用自助采样（约 36.8% 样本未被采到，即袋外 OOB）造出 T 个不同训练集。主要降低方差，适合不稳定学习器（决策树、神经网络）。
随机森林：Bagging + 属性扰动（每个节点从随机 K 个属性中选最优划分，推荐 K = log2d）。多样性来自样本扰动 + 属性扰动。副作用是训练更快（只在属性子集里找切点）。
袋外估计 OOB 拓展：约 36.8% 的样本没进某个基学习器，可以直接当它的验证集——随机森林因此不需要单独留验证集，用 oob_score 就能估计泛化误差。

④ 结合策略：平均、投票、学习法

平均法（回归；性能相近用简单平均，相差大用加权平均）、投票法（分类；绝对多数/相对多数/加权，绝对多数提供拒绝选项）、学习法（Stacking：用基学习器输出训练一个次级学习器，输入用类概率、次级用多响应线性回归 MLR 效果较好）。

⑤ 增强多样性的四种扰动

数据样本扰动（Bagging、AdaBoost）、输入属性扰动（随机森林）、输出表示扰动（ECOC、翻转法）、算法参数扰动（不同模型/不同超参混合）。
口诀：AdaBoost 串行降偏差、Bagging 并行降方差、随机森林在 Bagging 之上再加属性扰动。看到「降低方差」选 Bagging/随机森林，看到「降低偏差」选 Boosting。
考点视角：这是机器学习板块最常考的对比题：Boosting vs Bagging（串行/并行、样本权重/自助采样、降偏差/降方差）。再记一句：随机森林基学习器固定为决策树，且训练效率高于 Bagging 版决策树（因为只在属性子集中选划分）。工业界的 GBDT/XGBoost 属 Boosting 家族，详见本页 ML18。

ML11聚类：距离、原型、密度、层次 高频★★★

① 距离度量

闵可夫斯基距离 dist = (Σ|xi−xj|p)1/p；p=1 曼哈顿、p=2 欧氏、p→∞ 切比雪夫。有序属性（连续 + 有序离散）可直接算；无序属性用 VDM：VDMp(a,b) = Σk |mk,a/ma − mk,b/mb|p。
标准化提示 拓展：欧氏距离对量纲敏感，聚类前必须先标准化（z-score 或按业务权重缩放），否则"年收入"（万元级）会完全淹没"年龄"（十级）。

② 性能度量：外部指标与内部指标

外部指标（与参考模型比：Jaccard、FM、Rand 指数，基于 a/b/c/d 四量）、内部指标（不看外部：DB 指数——越小越好，Dunn 指数——越大越好）。直观标准：簇内高内聚、簇间低耦合。

③ 原型聚类：K-Means / LVQ / 高斯混合

K-Means：随机定类中心 → 按距离划簇 → 重算类中心 → 迭代至收敛；最小化平方误差 E = Σi ‖xi − μλi‖2。本质是 EM（类别=隐变量）。
LVQ：用真实类标辅助聚类——分对了原型向量靠近样本，分错了远离。
高斯混合聚类 GMM：每个簇是一个多维高斯分布，用 EM 估计 α、μ、Σ，按后验 γji 划分（软聚类，给出归属概率）。

④ 密度聚类 DBSCAN

核心对象 / 密度直达 / 密度可达 / 密度相连；找出核心对象所有密度可达的样本成簇。不需要预先指定 k，能发现任意形状簇、能识别噪声点；对参数（邻域半径 ε、MinPts）敏感，且密度不均匀时表现差。

⑤ 层次聚类 AGNES

自底向上，每次合并最近的两类；类间距离有三种——单链接（最小距离，包容、易形成链状）、全链接（最大距离，严格、偏好球状）、均链接（平均距离，折中）。Ward 法 拓展：合并使类内方差增量最小的一对，实务中最常用。产出是树状图 dendrogram，可事后在任意高度切出簇数。

⑥ k 怎么定？四个实用办法 拓展

肘部法（画 k–簇内平方和曲线，找拐点）、轮廓系数（s = (b−a)/max(a,b)，a 为同簇平均距离、b 为最近他簇平均距离，越接近 1 越好，取平均 s 最大的 k）、Gap Statistic（与均匀参考分布比较）、业务约束（最实用：能落地的运营动作有几个，就分几群）。
K-Means++：改进初始中心的选择（让中心彼此远离），大幅降低陷入坏局部解的概率；Mini-Batch K-Means：每次只用小批量更新中心，百万级数据的标配。
口诀：K-Means 要指定 k、球状簇、对初值敏感；DBSCAN 不需 k、任意形状、能去噪；层次聚类产出树状图（可事后切）。「k 未知或形状不规则 → DBSCAN」。
考点视角：① K-Means 流程与「需预先指定 k」这一前提；② DBSCAN 的四个概念与「不需指定簇数、能识别噪声」；③ 单/全/均链接的区别。选择题常给场景让你选算法。

ML12降维与度量学习 中频★★

① 维数灾难与低维嵌入

高维下样本稀疏、密采样所需样本数为天文数字、距离计算困难（这正是 SVM 要用核函数的原因）。降维即把高维空间嵌入合适的低维子空间（低维嵌入）。

② kNN：惰性学习的代表

无显式训练过程的惰性学习（训练开销为零，预测时才计算）；k 太小受噪声干扰（k=1 最极端），k 太大预测能力退化（k=m 时全猜一类），通常用交叉验证选 k。它常被用来为降维算法挑选低维维数。

③ MDS 与 PCA

MDS 多维缩放：要求降维前后样本间距离保持不变；由距离矩阵 D 求内积矩阵 B（中心化后 B = ZTZ），再做特征值分解得到低维坐标 Z。
PCA 主成分分析：线性变换投影到超平面，要求最近重构性（点到超平面距离近）与最大可分性（投影点尽量分散）——两条思路导出的优化问题完全相同；对协方差矩阵做特征值分解，取前 d′ 个大特征值对应的特征向量。

④ 核化与流形学习

KPCA：先映射到高维再线性降维；利用「空间中任一向量可由所有样本线性表出」，最终只需对核矩阵 K 做特征分解。
流形学习：Isomap（保持邻域内距离，用测地线距离 + MDS）、LLE（保持邻域内线性关系）。近邻图构建的两难：邻域过大「短路」、过小「断路」。
t-SNE / UMAP 拓展：现代可视化首选。t-SNE 用 t 分布刻画近邻相似、擅长展现局部结构；UMAP 更快、更能保留全局结构。注意：降维可视化后的"簇间距"没有定量含义，不能拿它当聚类结果用。

⑤ 马氏距离与度量学习

dist2 = (xi−xj)T M (xi−xj)；标准马氏距离中 M = Σ−1（协方差矩阵的逆），考虑属性相关性且尺度无关。度量学习就是学习这个度量矩阵 M（须为半正定对称）。

⑥ PCA 的两个易错点 拓展

⚠ 一、必须先中心化/标准化：PCA 的「方差最大」是相对原点的，未标准化的话量纲大的变量会霸占第一主成分。

考点视角：① 维数灾难的表现（稀疏 + 距离难算）；② PCA 的两个等价性质（最近重构 = 最大可分）；③ PCA 与 LDA 的区别（无监督/有监督）；④ kNN 是惰性学习。解释方差、累计贡献率是常见计算题。

ML13特征选择与稀疏学习 低频★

① 三种范式

过滤式（先选特征再训练；Relief 用「相关统计量」——猜中近邻 near-hit 越近越好、猜错近邻 near-miss 越远越好，多分类用 Relief-F）、包裹式（把学习器当评价准则，LVW 随机搜索 + 停止参数 T，开销大）、嵌入式（选择与训练融合，靠 L1 正则）。

② L1 vs L2：这一个点必考

L1（Lasso）使部分权重精确为 0 ⇒ 特征选择；L2（Ridge）使权重趋于 0 但不为 0 ⇒ 控过拟合。原因：L1 在 0 附近下降速度快（绝对值 vs 二次函数），且约束区域是菱形、更容易在顶点处与等高线相切得到稀疏解；L2 的约束区域是圆，切点落在坐标轴上的概率为零。

③ 子集搜索与评价

前向（逐步加）、后向（逐步减）、双向（加减并行）；评价可用信息增益。
其他常用筛选手段 拓展：互信息 / 卡方检验（离散特征与标签的相关）、RFE 递归特征消除（用模型权重反复砍最弱的一批）、Elastic Net（L1+L2 混合，兼顾稀疏与稳定性，高维相关特征时优于纯 Lasso）、排列重要性（打乱某列看性能掉多少，比树自带的 impurity importance 更可信）。
⚠ 树模型特征重要性的陷阱 拓展：基于不纯度下降的重要性会偏爱取值多的变量（高基数、连续变量占便宜），且只在训练集上算。要做特征选择请用排列重要性或 SHAP（见 ML21）。
口诀：过滤式快而粗、包裹式准而慢、嵌入式靠 L1。要「把没用的特征踢掉」用 L1，要「把权重压小防过拟合」用 L2。
考点视角：L1 与 L2 的区别是唯一高频点，务必说清「L1 稀疏、可做特征选择；L2 平滑、防过拟合」。与本站 CH.04 回归分析的 Ridge/Lasso 部分是同一知识的两个视角，可对照着看。

ML14计算学习理论：PAC 与 VC 维 低频★

① 三个基本概念

目标概念 c（理想映射）、假设空间 H（算法所有可能映射的集合）、可分/一致（假设空间包含目标概念）。

② PAC 与可学习性

PAC（概率近似正确）：以置信度 1−δ 学得泛化误差 ≤ ε 的假设。加上样本数要求 → PAC 可学习；再加上多项式时间 → PAC 学习算法。
有限假设空间（可分）：剔除经验误差不为 0 的假设，所需样本数 m ≥ (1/ε)(ln|H| + ln(1/δ))；不可分（不可知学习）时用 Hoeffding 不等式给出泛化误差界。

③ 增长函数、打散与 VC 维

增长函数：假设空间对 m 个样本能打出的最多标记结果数；打散：能实现全部 2m 种对分。
VC 维：假设空间能打散的最大数据集大小 d（存在大小为 d 的可打散集，但不存在 d+1 的）。结论：任何 VC 维有限的假设空间都是（不可知）PAC 可学习的。
例：二维平面上线性划分的 VC 维 = 3（能打散任意 3 点，打不散呈异或状的 4 点）。

④ 稳定性与结构风险最小化 拓展

稳定性：输入变动一个样本，输出损失变化不超过 β ⇒ β-均匀稳定性；满足 ERM 且 β-均匀稳定的假设空间可学习。
Rademacher 复杂度：衡量假设空间「拟合随机噪声的能力」，比 VC 维更紧、且与数据分布有关。
结构风险最小化 SRM：在「经验风险 + 复杂度惩罚」之间取平衡——正则化就是 SRM 的具体实现，VC 维/范数则是复杂度的度量。
考点视角：只需掌握三条定性结论：① PAC = 「大概率学得误差有界的假设」；② VC 维衡量假设空间复杂度（能打散的最大样本数）；③ VC 维有限 ⇒ 可学习。数值计算不考。

ML15半监督与自监督学习 低频★

① 主动学习 vs 半监督学习

主动学习挑不确定性高/置信度低的样本去问专家（仍需交互，本质还是监督）；半监督不与外界交互，直接利用未标记样本蕴含的分布信息（它们与有标记样本同分布）。

② 纯半监督 vs 直推学习

纯半监督：未标记数据不是待预测数据；直推学习：未标记数据就是待预测数据。区分点只看「未标记样本是不是最终要预测的那批」。

③ 四类半监督方法

① 生成式方法（假设高斯混合分布，EM 求解；强依赖分布假设，假设错了反而更差）；② 半监督 SVM（TSVM/S3VM）（让超平面穿过低密度区域，给未标记样本伪标记并局部搜索调整）；③ 基于分歧（协同训练：多视图相容互补，各自挑置信度最高的样本给对方学）；④ 半监督聚类（必连/勿连约束，或少量带标记样本指定类中心）。

④ 自监督学习：把数据本身当标签 拓展

自监督从数据自身构造监督信号：生成式（BERT 的遮词预测 MLM、GPT 的下一个词预测、自编码器的重建）、对比式（SimCLR：同一张图的两个增强视角要「近」、不同图要「远」，靠 InfoNCE 损失拉开距离）。
意义：把海量的无标签数据用起来——这正是大模型能做到「通才」的根本。保险里的对应场景：海量未标注理赔文本/医疗影像先做预训练，再用少量标注微调。
考点视角：命题点很集中——主动学习 vs 半监督的区别（是否需交互/查询）、纯半监督 vs 直推学习的区别（未标记样本是不是待预测样本）。

ML16概率图模型：HMM / MRF / CRF 中频★★

① 有向图与无向图

用有向边表依赖关系 → 贝叶斯网（如 HMM，箭头表因果/生成方向）；用无向边 → 马尔可夫网（如 MRF，边表相关/约束）。

② HMM：三参数三问题

状态变量（隐）与观测变量（显）。两条依赖：① 观测只依赖当前状态；② 下一状态只依赖当前状态（马尔可夫性：现在决定未来，未来与过去无关）。三组参数：初始状态概率 π、状态转移概率 A、观测概率 B。
三个问题：评估（求序列概率 → 前向算法）、解码（求最可能状态序列 → Viterbi 算法，动态规划）、学习（只给观测序列调参 → EM / Baum-Welch）。

③ MRF 与 CRF

MRF：团（两两有边相连的子集）、极大团；联合概率按极大团上的势函数分解：P(x) = (1/Z) ΠQ∈C ψQ(xQ)（Z 为规范化因子，难算）。三条马尔可夫性：全局 / 局部 / 成对。
CRF：对条件分布 P(y|x) 建模（判别式），与 HMM（生成式）相对；链式 CRF 用两类特征函数——转移特征（相邻标注是否合理）、状态特征（观测与标注是否匹配）。条件建模省去了对 P(x) 的建模，序列标注任务上通常优于 HMM。

④ 精确推断与图神经网络 拓展

变量消去（用乘法分配律把求和控制在局部）、信念传播（叶→根、根→叶两轮消息传递，节点边际正比于所收消息之积；树结构精确、有环图用 Loopy BP 近似）。
GNN 图神经网络：把「图结构 + 神经网络」结合，靠消息传递（聚合邻居信息）学习节点/边/图的表示。保险里的杀手级应用是欺诈团伙识别——把报案人、修理厂、医院、受益人建成关系图，团伙在图上有明显的结构特征（见 ML23）。
与本站 CH.01 的呼应：马氏链在风险理论里是「状态转移 + 稳态分布」（本站统一用「常态/瞬态」表述），在 HMM 里是「隐状态序列的依赖结构」——同一个数学对象，两种用法。
考点视角：① 有向=贝叶斯网、无向=马尔可夫网；② HMM 三参数三问题（评估/解码/学习对应前向/Viterbi/EM）；③ HMM 是生成式、CRF 是判别式。

ML17强化学习 低频★

① MDP 四要素

状态 X（对环境的感知）、动作 A、转移概率 P、奖赏函数 R。目标是学出策略 π（确定性 π(x)=a 或随机性 π(x,a)），使长期累积奖赏最大（T 步累积奖赏 / γ 折扣累积奖赏，γ∈(0,1) 权衡眼前与长远）。

② 探索-利用困境

仅探索（均分机会，估得准但不利用）、仅利用（只试当前最优，易陷局部）。折中：ε-贪心（以 ε 概率随机探索、1−ε 概率利用）、Softmax（按当前平均奖赏的 softmax 概率分配）。更好的做法是UCB（置信上界）与汤普森采样——按不确定性大小分配探索预算。

③ 有模型 vs 免模型

有模型（四要素已知）：策略评估（状态值函数 V、状态-动作值函数 Q，用 Bellman 等式递归）+ 策略改进（选当前最优动作）。策略迭代（评估与改进交替）与值迭代（先迭代出最优值函数）。
免模型（转移与奖赏未知）：蒙特卡罗强化学习，靠采样轨迹估计 Q，用 ε-贪心保证多样性；同策略（SARSA，学的是正在执行的策略）vs 异策略（Q-learning，学的是最优策略）。

④ 深度强化学习与现代版图 拓展

DQN：用神经网络拟合 Q 函数，两大稳定器是经验回放（打破样本时间相关）与目标网络（延迟更新，避免追着自己的尾巴跑）。
策略梯度 / Actor-Critic / PPO：直接对策略参数化求梯度，PPO 用「截断的重要性采样」限制每步更新幅度，稳定又好调，是工业界默认。
RLHF（人类反馈强化学习）：先训练奖励模型拟合人类偏好，再用 PPO 优化——大语言模型的对齐就是这么做的。
保险里的应用：动态定价与续保策略（每一步动作会影响客户后续状态）、再保/资产配置的序贯决策研究、以及客服话术优化。落地难点是不能在真实客户身上试错，必须先有离线模拟器（off-policy evaluation）。
AlphaGo 三模块：深度学习（拟合估值函数）+ 蒙特卡罗搜索树（采样）+ 强化学习（按反馈调整估值函数）。这是「三大件如何配合」最好的例子。
考点视角：考纲对强化学习只要求了解。掌握：四要素、探索-利用困境与 ε-贪心、V/Q 值函数的含义即可。

ML18梯度提升家族：GBDT → XGBoost → LightGBM → CatBoost 拓展

① 从 AdaBoost 到梯度提升：换个损失函数就够了

AdaBoost 的本质是「用加性模型拟合指数损失」。把损失函数换成任意可微损失（平方损失、对数损失、Huber、分位数损失……），让每一棵新树去拟合当前模型损失函数的负梯度，就是 梯度提升 GBDT。
预测形式：ŷi = Σt=1..T η·ft(xi)，η 为学习率（收缩）——把每棵树的贡献缩小，用更多棵树换更小的过拟合风险，这是 GBDT 最重要的一个旋钮。
平方损失下，负梯度 = 残差 y − ŷ，所以「GBDT 就是不断拟合残差」；其他损失下拟合的是更一般的伪残差。分位数损失还能直接给出预测区间——对准备金与资本建模很有用。

② Boosting vs Bagging：一图看懂两种集成

图四 · Bagging 与 Boosting 的结构差异：前者并行 + 平均（降方差），后者串行 + 加权累加（降偏差）。这也是随机森林与 XGBoost 表现差异的根源。

③ XGBoost：二阶展开 + 显式正则

目标函数在每轮做二阶泰勒展开：Obj(t) ≈ Σi [gi ft(xi) + ½ hi ft2(xi)] + Ω(ft)，其中 gi = 一阶导（梯度）、hi = 二阶导（Hessian），Ω 为正则项。
正则项：Ω(f) = γT + ½λ‖w‖2 —— 惩罚叶子数 T 与叶子权重 w 的平方，这是 XGBoost 抗过拟合的关键。
对一棵固定结构的树，叶 j 的最优权重有闭式解：wj* = −Gj / (Hj + λ)，其中 Gj = Σi∈j gi、Hj = Σi∈j hi。
对应分裂增益：Gain = ½ [ GL²/(HL+λ) + GR²/(HR+λ) − (GL+GR)²/(HL+HR+λ) ] − γ。
Gain > 0 才值得分裂；γ 是「分裂的门槛费」，λ 是「权重收缩度」。

③ SHAP：目前最主流的一把尺子

SHAP 把每个特征的贡献看作合作博弈中的 Shapley 值——在所有特征加入顺序上，该特征带来的平均边际贡献。它满足效率性（所有 SHAP 值之和 = 预测值 − 基线）、对称性、可加性，是目前理论性质最好的局部解释方法。
树模型有专门的 TreeSHAP（多项式时间精确解），这是 XGBoost/LightGBM 生态里最常用的解释工具。
一个常被忽略的区分 SHAP 解释的是「模型为什么这么预测」，不是「现实为什么是这样」。如果模型学的是数据里的偏见（比如某地区历史赔付高是因为早年核保松），SHAP 会如实告诉你模型用了它——它不负责判断这个因子合不合理。合理性要靠人审、要靠公平性检验。

④ 公平性、漂移与模型监控

群体公平指标：统计均等（各受保护群体的正例率相同）、机会均等（各群体的 TPR 相同）、预测均等（各群体的 PPV 相同）——三者一般不可同时满足（不可能定理），必须按业务选一个并写进文档。
最朴素有效的做法：先跑一个不含敏感属性的模型，比较含/不含两种情形下的分组差异，再看差异是否可接受。
漂移监测：上线后要盯三类漂移——特征漂移（X 分布变了，如客户年龄结构变化）、概念漂移（P(y|x) 变了，如欺诈手法更新）、标签延迟（保险里赔款要一年后才结清，"真实标签"本身就滞后）。
最常用指标是 PSI 群体稳定性指数：PSI = Σ (实际占比 − 预期占比) × ln(实际/预期)。

ML22定价：GLM 与 GBM 的正面交锋 拓展

① 精算定价的标准答案：GLM 频率-强度双层模型

非寿险定价的经典做法是拆成两层：
频率：索赔次数 N ~ Poisson(λ·e)，ln λ = Xβ，offset = ln(暴露量 e)；
强度：单次赔款 Y ~ Gamma（或对数正态），ln μ = Xγ，权重 = 索赔次数；
纯保费 = 频率 × 强度。
也可以一步到位用 Tweedie（复合 Poisson-Gamma，p∈(1,2)），同时建模零膨胀与连续正赔付，建模与工程都更省事。
为什么对数链接是默认：① 保证预测值恒为正；② 把乘法结构变成加法（因子相乘 = 线性相加），天然对应「基准费率 × 各因子系数」的商业语言；③ 系数可直接读成相对费率（eβ = 倍数）。

优势说明在保险里有多重要

稳定且外推合理参数少、方差小，新组合也能给出合理值新车型、新地区上市时不能给出荒谬价格
理论成熟标准误、显著性检验、可信度理论（Bühlmann-Straub）可直接衔接中小样本、新业务线的经验调整有章可循
生态完备精算师都会、监管都认、报表都能对接落地成本最低
它的短板：对数线性假设（对连续变量要分箱或用样条）、交互项要手工构造、对高基数类别变量吃力、预测精度（Gini）通常低于 GBM 几个点。

③ GBM 能带来什么，代价是什么

带来：自动捕捉非线性与高阶交互（「年轻 + 高性能车 + 一线城市」这种三阶组合）、自动处理高基数变量、Gini 常能提升 3~10 个点。
代价：① 黑箱，难以向监管与客户解释；② 概率未必校准（需专门校正）；③ 不会外推（树只能输出见过的区间）；④ 需要单调性约束才能让费率表符合直觉；⑤ 特征重要性会偏爱高基数变量。

④ 三条务实的融合路线

路线 A（最常用）：GBM 找交互，GLM 落地——先用 GBM 跑一遍，看 SHAP 交互值或做残差分析，找出真正有业务含义的交互项，手工加进 GLM，得到既准又可解释的费率表。
路线 B（折中）：GLM 基准 + GBM 残差——用 GLM 做主结构，GBM 只拟合残差部分，并限制其幅度（如 ±20%），保证可解释主体 + 精度增量。
路线 C（进阶）：可加 GBM / EBM——把 GBM 限制成「各特征贡献之和」（不允许交互），既能自动学形状、又能画出每个特征的效应曲线，解释性与精度的折中点。

⑤ 定价建模的检查清单

检查项常见错误正确做法
暴露量用「保单件数」当分母，忽略中途退保与短期单用已赚暴露（earned exposure）并作为 offset 进入模型
赔付延迟与 IBNR直接用已付赔款，低估近期年度用已发生赔款（incurred）或对近年度做进展因子调整
通货膨胀与趋势把多年数据混在一起，趋势被平均掉加入事故年度/进展期因子，或对赔款做通胀调整
零膨胀与长尾用普通最小二乘拟合赔款Tweedie、两部模型（频率×强度）、或对大额做截尾
时间外验证随机切分，模型偷看未来按事故年度/承保年度切，最近一年做 OOT
可信度与平滑小样本地区/车型给出极端系数Bühlmann 可信度加权、或对小类别做层级收缩（mixed model / 目标编码平滑）
校准只看 Gini/KS，不看总体水平检查 实际 vs 预期（A/E）比，按主要因子分层看是否 ≈ 1
一句话总结：定价不是预测比赛，是「在可解释、可审计、可销售的约束下，把风险区分度做到最好」。GBM 赢了 Gini 但输了审计，这笔账在保险业通常不划算——除非你把它放在 GLM 的框架里用。

ML23理赔 · 准备金 · 客户经营 拓展

① 反欺诈：一个「正例很少且不准」的极端问题

理赔欺诈的典型特征：正例率 < 1%；标签不可靠（只有被查实的部分标记为欺诈，未被发现的仍混在负例里）——这在方法上叫 PU learning（正例-未标记学习），比普通半监督更麻烦，因为负例其实是「未标记」。
所以欺诈模型的正确打开方式是：规则打底（专家经验的硬规则）+ 模型排序（给调查员一份优先级名单）+ 人工复核（结果回流成新标签），而不是「模型自动拒赔」。
关键技术选择：评估看 P-R 曲线与 Lift（不要看准确率）；阈值按调查成本 vs 追回金额定（见 ML3 的代价敏感演算器）；解释用 SHAP 给调查员写「为什么可疑」；关系型欺诈（团伙、修理厂串通）用 图神经网络 / 关联特征（同一地址、同一修理厂、同一手机号）。

② 准备金：链梯法之外的新工具

传统方法是聚合（macro）层面的三角形法：链梯法、Bornhuetter-Ferguson、Cape Cod。
机器学习能做个体（micro）层面：以每一条已报案赔案为单位，预测它的最终赔付额 / 是否已结案 / 未来进展路径，再汇总成准备金。
优势：能吃进个体特征（伤情、责任比例、理赔员、治疗方式），对同质化程度低的业务（如责任险、健康险）提升明显；风险：个体模型方差大、对数据质量依赖高，且难以满足「基于稳定历史模式」的审计直觉。
务实做法：两套并行、差异分析——把机器学习结果当「第二意见」，两者差异就是需要精算判断的重点。

③ 客户经营：续保、退保与客户价值

退保/续保预测本质是带时间的二分类，与本站 CH.02 生存分析直接相通：把「是否退保」+「何时退保」一起建模，用 Cox 模型 / 离散时间 Logistic / 随机生存森林，比普通分类器更合适（也更能处理截尾——观察期末还没退的保单）。
客户分群：K-Means/层次聚类 + RFM（最近一次、频率、金额）特征，落到可运营的几群人。
CLV 客户终身价值：把未来若干年的保费收入 - 预期赔付 - 费用折现，本质是「续保概率 × 每年边际贡献」的逐年求和。

④ Uplift 增量建模：营销场景的正确问法

普通响应模型预测「谁会买」， uplift 模型预测「谁会因为我的动作而改变」——把客户分成四类：易说服者（不发不买、发了就买，该发）、必买者（发不发都买，别浪费）、流失者（发了反而不买，千万别发）、无动于衷者（都不买）。
做法：两模型差分（分别用处理组/对照组建模型，取预测差）、类别转换、因果森林；评估用 Qini 系数 / AUUC（ uplift 曲线下面积）。
为什么精算师该关心：续保优惠券、加保推荐、健康管理干预——所有「花了钱要看到增量」的场景，问的都是 uplift 问题，而不是响应概率问题。
